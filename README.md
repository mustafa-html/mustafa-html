| 📊 | **[Allocated Stock Exchange](https://github.com/mustafa-html/Allocated-Stock-Exchange)** | A trading engine that matches buy and sell orders by price-time priority — Limit, Market, GTC, Fill & Kill — with a live order book dashboard and a Go gateway sharding traffic across engines. | `C++` `Go` `Next.js` |
| 🧙 | **[Multi Persona AI Advisor](https://github.com/mustafa-html/Multi-Persona-AI-Advisor)** | Pick four advisors from ten personalities and get all four takes at once. Fires the API calls concurrently so four answers cost the time of one, in an animated 3D scene. | `React` `Three.js` `OpenAI` |
| 📈 | **[Stock Predictor](https://github.com/mustafa-html/Stock-predictor)** | Feeds market data to an LSTM, forecasts prices, then backtests to see how wrong it was. Ships with a dashboard. | `Python` `TensorFlow` `Flask` |
| 🏦 | **[Banking Dashboard](https://github.com/mustafa-html/Banking-And-Finance-Management-Dashboard)** | Link a real bank account, see balances and transactions, move money. Full-stack, real financial APIs. | `TypeScript` `Next.js` `Plaid` |
| 🫀 | **[ECG R-Peak Detection](https://github.com/mustafa-html/ECG-R-Peak-Detection)** | Finds heartbeats in raw ECG signal at 100% sensitivity and precision against clinical annotations — built and tested the way medical devices are, scored to ANSI/AAMI EC57. | `Python` `SciPy` `pytest` |
| 🚨 | **[Threat Detection & Response](https://github.com/mustafa-html/Threat-Detection-Response)** | Spots sketchy activity and blocks it live. SIEM export and Prometheus metrics included. | `Python` `Prometheus` `SIEM` |
| 🔐 | **[Secure Policy AI](https://github.com/mustafa-html/Secure-Policy-AI)** | Ask security policies questions in plain English. RAG pipeline, so the answers are grounded in the real docs. | `Python` `ChromaDB` `Streamlit` |
| 📅 | **[Syllabus2Cal AI](https://github.com/mustafa-html/Syllabus2Cal-AI)** | Eats a chaotic course syllabus, spits out every deadline as calendar events. One click instead of one hour. | `Python` `NLP` `LLM` |
| 🏀 | **[NBA Outcome Predictor](https://github.com/mustafa-html/NBA-Match-Outcome-Predictor)** | Predicts game winners at 72% accuracy on held-out data, trained on 10,000+ games. Preprocessing rework cut training time 40%. | `Python` `pandas` `scikit-learn` |
| ⚙️ | **[Business Process Automation](https://github.com/mustafa-html/BusinessProcessAutomationTool)** | Kills repetitive back-office busywork and reports on what it killed. | `C#` `SQL Server` `Power BI` |
